HTTP на практике

Задание выполняется дома на любом компьютере: нужны только браузер и терминал. Операционная система — любая (Windows, macOS, Linux). Программировать можно на любом языке — или вообще без языка (часть 3, способ Б).

Перед началом (Windows). Терминал: Win+R → cmd → Enter. Curl встроен в Windows 10/11, но в PowerShell слово curl занято под другое — пишите curl.exe (с «.exe»). Проверка: curl.exe --version. DevTools в браузере: F12 (Network — запросы, Application — cookie). Если httpbin.org недоступен — запасной адрес: https://api.github.com.
Что я хочу видеть в работе
  1. Ваши выводы команд. В отчёт идёт то, что напечатал ваш терминал на вашем компьютере — с вашими адресами, именами и размерами.
  2. Вывод-строка к каждому заданию. После команды и её вывода — своими словами: что вы увидели и что это значит. Не пересказ теории, а ваше наблюдение.
  3. Скриншоты с панелью DevTools. На скриншоте видна вкладка (Network / Application) и выделенный запрос — чтобы было понятно, что смотрите именно вы.
  4. Работающий скрипт части 3 и результат запуска. Я должен запустить ваш файл по вашей инструкции и увидеть то же, что видели вы.
  5. Честные неудачи. Если что-то не получилось — напишите, на каком шаге и какая была ошибка. Это ценнее, чем скопированный чужой успех.
01HTTP руками в терминале
1.1 · Заголовки живого сайта
curl.exe -sI https://example.com

Выпишите из ответа: статус-код, заголовки Server и Content-Type. В отчёт: команда, весь вывод и одной строкой — что означает каждый пункт.

1.2 · Три кода ответа

Найдите адреса, которые дают:

  • 200 — любой существующий сайт;
  • 3xx — редирект, подсказка: curl.exe -sI https://httpbin.org/redirect/2 (сокращатели ссылок тоже подходят, но не все);
  • 404 — любой сайт + несуществующая страница, например /takoi-stranitsy-net.

В отчёт: таблица адрес | код | что означает + ответ одной строкой: чем 3xx отличается от 404 с точки зрения браузера?

1.3 · POST с телом запроса
curl.exe -d '{ "name": "Ivan" }' -H "Content-Type: application/json" https://httpbin.org/post

Сервис «эхом» возвращает всё, что вы отправили. Найдите в ответе раздел json — там ваши данные. Поменяйте имя на своё и отправьте снова.

В отчёт: обе команды и оба ответа (можно сократить до раздела json).

02DevTools-детектив

Откройте любой сайт (кроме поисковиков), нажмите F12 → вкладка Network → обновите страницу (Ctrl+R).

2.1 · Найдите редирект

Найдите в списке запрос со статусом 301/302, кликните по нему. В Headers найдите заголовок Location — куда сервер отправил браузер?

В отчёт: сайт, статус, адрес из Location.

2.2 · Сколько весит страница

Отсортируйте список по колонке Size и найдите самый тяжёлый ресурс. Внизу панели — суммарная статистика: сколько всего запросов и килобайт.

В отчёт: самый тяжёлый ресурс (имя и размер), число запросов, общий объём.

2.3 · Cookie

Вкладка Application (Firefox: Хранилище) → Cookies. Выпишите имя одного cookie и первые ~20 символов значения.

В отчёт: имя, кусочек значения и ваше предположение — зачем этот cookie: сессия, настройки, реклама?

2.4 · GET против POST

С открытой панелью Network выполните поиск по сайту и попытку входа (любой сайт с логином). Сравните: у какого запроса данные видны в адресе (после «?»), а у какого — в теле (вкладка Payload)?

В отчёт: два скриншота или описания — где оказались данные формы в GET и в POST.

03Автоматизация запроса

Задание одно: сделать GET-запрос к https://httpbin.org/json и вывести: 1) статус-код, 2) заголовок Content-Type, 3) значение поля title из ответа. Выберите один из трёх способов — какой удобнее.

А · POWERSHELL

Встроен в Windows. Сохраните в файл get.ps1:

$r = Invoke-WebRequest "https://httpbin.org/json"
$r.StatusCode
$r.Headers["Content-Type"]
($r.Content | ConvertFrom-Json).slideshow.title

Запуск: powershell -ExecutionPolicy Bypass -File get.ps1

Б · КОНСОЛЬ БРАУЗЕРА

Без инструментов: F12 → Console → вставьте:

fetch("https://httpbin.org/json")
  .then(r => { console.log(r.status,
    r.headers.get("Content-Type"));
    return r.json(); })
  .then(j => console.log(
    j.slideshow.title));

Скриншот результата консоли.

В · ЛЮБОЙ ЯЗЫК

Python, Java, C# — что угодно. Отправьте запрос, разберите ответ.

Приложите исходник и строку «как запустить».

Дополнительно: пусть скрипт не падает при отсутствии интернета, а печатает понятное сообщение, и умеет печатать все заголовки ответа.

Как сдавать

Один архив Фамилия_HTTP.zip, внутри:

· otchet.txt — отчёт по частям 1 и 2: для каждого задания — что делали, команда, вывод (или скриншот), вывод одной строкой;

· скриншоты DevTools (часть 2);

· файл скрипта части 3 + строка «как запустить» (или скриншот консоли — если способ Б).

Скриншоты и выводы должны быть вашими.
