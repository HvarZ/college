Задание выполняется дома на любом компьютере: нужны только
браузер и терминал. Операционная система - любая (Windows,
macOS, Linux). Программировать можно на любом языке - или
вообще без языка (см. часть 3).


ПЕРЕД НАЧАЛОМ (для Windows)
----------------------------------------------------------------
1. ТЕРМИНАЛ: Win + R, введите cmd, Enter.

2. CURL: в Windows 10/11 curl встроен. В PowerShell слово
   "curl" занято под другое - пишите curl.exe (с ".exe").
   В cmd работает просто curl. Проверка: curl.exe --version

3. DEVTOOLS: в браузере нажмите F12 (или Ctrl+Shift+I).
   Network - запросы, Application - cookie.

4. Если httpbin.org недоступен - запасной адрес для
   части 3: https://api.github.com

ЧАСТЬ 1. HTTP РУКАМИ В ТЕРМИНАЛЕ
----------------------------------------------------------------

Задание 1.1. Заголовки живого сайта
Команда:
    curl.exe -sI https://example.com
Выпишите из ответа: статус-код, заголовки Server и
Content-Type. В отчёт: команда, весь вывод и одной строкой -
что означает каждый пункт.

Задание 1.2. Три кода ответа
Найдите адреса, которые дают:
    - код 200 (успех)   - любой существующий сайт
    - код 3xx (редирект):
        curl.exe -sI https://httpbin.org/redirect/2
    - код 404 (не найдено) - любой сайт + несуществующая
      страница
В отчёт: таблица адрес | код | что означает. Плюс ответ
одной строкой: чем 3xx отличается от 404 с точки зрения
браузера?

Задание 1.3. POST с телом запроса
Команда:
    curl.exe -d '{ "name": "Ivan" }' -H "Content-Type:
    application/json" https://httpbin.org/post
Сервис httpbin "эхом" возвращает всё, что вы отправили.
Найдите в ответе раздел json - там ваши данные. Поменяйте
имя на своё - отправьте снова.
В отчёт: обе команды и оба ответа (можно сократить до
раздела json).


----------------------------------------------------------------
ЧАСТЬ 2. DEVTOOLS-ДЕТЕКТИВ
----------------------------------------------------------------
Откройте любой сайт, нажмите F12, вкладка Network,
обновите страницу (Ctrl+R).

Задание 2.1. Найдите редирект
Найдите в списке запрос со статусом 301 или 302, кликните
по нему. В Headers найдите заголовок Location - куда сервер
отправил браузер?
В отчёт: сайт, статус, адрес из Location.

Задание 2.2. Сколько весит страница
Отсортируйте список по колонке Size и найдите самый тяжёлый
ресурс страницы. Внизу панели - суммарная статистика:
сколько всего запросов и килобайт.
В отчёт: самый тяжёлый ресурс (имя и размер), число
запросов, общий объём.

Задание 2.3. Cookie
Вкладка Application (Firefox - Хранилище) -> Cookies.
Выпишите имя одного cookie и первые ~20 символов значения.
В отчёт: имя, кусочек значения и ваше предположение: зачем
этот cookie - сессия, настройки, реклама?

Задание 2.4. GET против POST
С открытой панелью Network выполните поиск по сайту и
попытку входа (любой сайт с логином). Сравните: у какого
запроса данные видны в адресе (после "?"), а у какого - в
теле (вкладка Payload)?
В отчёт: два скриншота или описания - где оказались данные
формы в GET и в POST.


----------------------------------------------------------------
ЧАСТЬ 3. АВТОМАТИЗАЦИЯ ЗАПРОСА
----------------------------------------------------------------

Задание одно: сделать GET-запрос к https://httpbin.org/json
и вывести: 1) статус-код, 2) заголовок Content-Type,
3) значение поля title из ответа.

Выберите ОДИН из трёх способов.

СПОСОБ А. POWERSHELL (встроен в Windows). Сохраните в файл
get.ps1:
    $r = Invoke-WebRequest -Uri "https://httpbin.org/json"
    $r.StatusCode
    $r.Headers["Content-Type"]
    ($r.Content | ConvertFrom-Json).slideshow.title
Запуск: powershell -ExecutionPolicy Bypass -File get.ps1

СПОСОБ Б. КОНСОЛЬ БРАУЗЕРА. F12 -> Console -> вставьте:
    fetch("https://httpbin.org/json")
      .then(r => { console.log(r.status,
        r.headers.get("Content-Type")); return r.json(); })
      .then(j => console.log(j.slideshow.title));
Скриншот результата консоли.

СПОСОБ В. ЛЮБОЙ ЯЗЫК (Python, Java, C#, что угодно):
отправьте запрос, разберите ответ. Приложите исходник и
строку "как запустить".

Дополнительно: пусть скрипт не падает при отсутствии
интернета, а печатает понятное сообщение, и умеет печатать
все заголовки ответа.
