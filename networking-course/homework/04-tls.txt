  TLS И СЕРТИФИКАТЫ

Задание выполняется дома на любом компьютере: нужны браузер
и терминал. Операционная система - любая (Windows, macOS,
Linux). Программировать не нужно.

Сайты для заданий 1.1, 1.2 и 2.1 выбирайте по правилу: домен
должен начинаться с ПЕРВОЙ БУКВЫ ВАШЕЙ ФАМИЛИИ в латинской
раскладке. Примеры: Иванов - буква I, Петров - P,
Смирнов - S. Если на букву фамилии сайт найти не удалось -
возьмите первую букву имени.

Запрещены: example.com и сайты, упомянутые в слайдах и в
этом листе. В отчёт укажите фамилию и выбранный сайт.
Сайт, не соответствующий правилу, задание не засчитывается.


ПЕРЕД НАЧАЛОМ (для Windows)
----------------------------------------------------------------
1. ТЕРМИНАЛ: Win + R, введите cmd, Enter.

2. OPENSSL: входит в Git for Windows. Запустите "Git Bash"
   (Пуск -> Git Bash). Проверка: openssl version
   Если Git Bash нет - установите с git-scm.com или
   используйте WSL.

3. CURL: встроен в Windows 10/11. В PowerShell пишите
   curl.exe (с ".exe").

4. ПАНЕЛЬ СЕРТИФИКАТА в браузере: значок замка слева от
   адреса -> "Соединение защищено" -> сведения о
   сертификате.

----------------------------------------------------------------
ЧАСТЬ 1. СЕРТИФИКАТ В ТЕРМИНАЛЕ
----------------------------------------------------------------
В командах замените ВАШ_САЙТ на выбранный домен (например,
mydomain.ru - но именно ваш, не из примера в скобках).

Задание 1.1. Поля сертификата
Команда:
    openssl s_client -connect ВАШ_САЙТ:443 \
      -servername ВАШ_САЙТ </dev/null \
      | openssl x509 -noout -subject -issuer -dates
Выпишите subject, issuer, notBefore, notAfter.
Ответьте: кто выдал сертификат и на сколько дней он выдан
(посчитайте от notBefore до notAfter).

Задание 1.2. Цепочка сертификатов
Команда:
    openssl s_client -connect ВАШ_САЙТ:443 -servername ВАШ_САЙТ
Команда не завершается сама; выход - Q или Ctrl+C.
Найдите в выводе строки depth=2, depth=1, depth=0 и строку
"Verify return code".
Ответьте: сколько звеньев в цепочке; как называется
корневой центр; что означает выведенный код проверки.


----------------------------------------------------------------
ЧАСТЬ 2. СЕРТИФИКАТ В БРАУЗЕРЕ
----------------------------------------------------------------

Задание 2.1. Панель сертификата
Откройте ваш сайт из части 1. Замок -> "Соединение
защищено" -> сведения о сертификате.
Ответьте: перечислите имена из поля SAN (не больше
четырёх); есть ли среди них имя со звёздочкой (*) и какие
поддомены оно покрывает; совпадают ли издатель и срок в
панели браузера с выводом openssl из задания 1.1.
Приложите скриншот панели.

Задание 2.2. Предупреждения браузера
Откройте по очереди три адреса (кнопку "продолжить" не
нажимайте):
    https://expired.badssl.com
    https://self-signed.badssl.com
    https://wrong.host.badssl.com
Для каждого адреса определите, какая из четырёх проверок
браузера не прошла: цепочка до доверенного корня / срок
действия / имя в SAN / доверие к издателю.
Приложите по одному скриншоту и напишите ответ.
