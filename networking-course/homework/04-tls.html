TLS и сертификаты

Задание выполняется дома на любом компьютере: нужны только браузер и терминал. Операционная система — любая (Windows, macOS, Linux). Программировать не нужно.

Выбор сайта. Для заданий 1.1, 1.2 и 2.1 выберите любой HTTPS-сайт, домен которого начинается с первой буквы вашей фамилии в латинской раскладке. Примеры: Иванов — буква I, Петров — P, Смирнов — S. Если на букву фамилии сайт найти не удалось — возьмите первую букву имени. Запрещены: example.com и сайты, упомянутые в слайдах и в этом листе. В отчёте укажите фамилию и выбранный сайт. Сайт, не соответствующий правилу, задание не засчитывается.
Перед началом (Windows). Терминал: Win+R → cmd → Enter. Команды openssl в чистом Windows нет — она входит в Git for Windows: запустите Git Bash (Пуск → Git Bash). Проверка: openssl version. Если Git Bash нет — установите с git-scm.com или используйте WSL. curl встроен в Windows 10/11, в PowerShell пишите curl.exe. Панель сертификата в браузере: замок слева от адреса → «Соединение защищено» → сведения о сертификате.
Требования к отчёту
  1. Команда и её вывод — с вашего компьютера, с вашим сайтом.
  2. Ответ на каждый вопрос задания — своими словами. Ответ вида «скопировал вывод, там всё видно» не принимается.
  3. Скриншоты — только там, где задание их просит. На скриншоте видна адресная строка или открытая панель.
  4. Если что-то не получилось — опишите, на каком шаге и какая была ошибка.
01Сертификат в терминале

В командах замените ВАШ_САЙТ на выбранный домен.

1.1 · Поля сертификата
openssl s_client -connect ВАШ_САЙТ:443 -servername ВАШ_САЙТ </dev/null \
  | openssl x509 -noout -subject -issuer -dates

Выпишите subject, issuer, notBefore, notAfter. Ответьте: кто выдал сертификат и на сколько дней он выдан (посчитайте от notBefore до notAfter).

1.2 · Цепочка сертификатов
openssl s_client -connect ВАШ_САЙТ:443 -servername ВАШ_САЙТ

Команда не завершается сама; выход — Q или Ctrl+C. Найдите в выводе строки depth=2, depth=1, depth=0 и строку Verify return code.

Ответьте: сколько звеньев в цепочке; как называется корневой центр; что означает выведенный код проверки.

02Сертификат в браузере
2.1 · Панель сертификата

Откройте ваш сайт из части 1. Замок → «Соединение защищено» → сведения о сертификате.

Ответьте: перечислите имена из поля SAN (не больше четырёх); есть ли среди них имя со звёздочкой (*) и какие поддомены оно покрывает; совпадают ли издатель и срок в панели браузера с выводом openssl из задания 1.1. Приложите скриншот панели.

2.2 · Предупреждения браузера

Откройте по очереди три адреса (кнопку «продолжить» не нажимайте):

  • https://expired.badssl.com
  • https://self-signed.badssl.com
  • https://wrong.host.badssl.com

Для каждого адреса определите, какая из четырёх проверок браузера не прошла: цепочка до доверенного корня / срок действия / имя в SAN / доверие к издателю. Приложите по одному скриншоту и напишите ответ.
