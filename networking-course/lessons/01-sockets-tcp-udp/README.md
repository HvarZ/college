# Урок 1. Сокеты, TCP и UDP

Презентация урока по предмету «Сетевое программирование».

## Запуск

**Открыть `index.html` в браузере — двойной клик. Больше ничего не нужно.**

Никакого сервера, интернета и команд: всё вендорено внутри директории
(reveal.js, шрифты, подсветка кода). Можно скопировать на флешку и
запустить на любой машине с браузером.

## Управление

| Клавиша | Действие |
|---------|----------|
| `→` / `←` | основная линия рассказа (вправо/влево) |
| `↓` / `↑` | **доп. факты** внутри темы (вертикальные слайды) |
| `O` | карта темы — сетка всех слайдов |
| `F` | полный экран |
| `Esc` | выход из режима обзора |

Переходы — `slide`: анимация идёт в сторону нажатой стрелки
(эффект «панорамирования по карте»).

## Структура урока

```
Титул → Разогрев → Сокет = IP+порт → Жизненный цикл → TCP handshake → TCP vs UDP
                         │                │                  │
                         ↓                ↓                  ↓
                   Berkeley 1983    Java ServerSocket   Заголовок TCP
```

- 6 основных слайдов (горизонтальная линия)
- 3 вертикальных «доп. факта» — тёмнее фон, фиолетовый лейбл «↓ Доп. факт»
- подсветка Java-кода, SVG-диаграмма handshake, таблица заголовка TCP
- заметки спикера сохранены в HTML (`aside.notes`), скрыты стилем —
  можно читать при подготовке прямо в исходнике

## Файлы

- `index.html` — презентация
- `theme/course-dark.css` — тема курса (тёмная, палитра tokyo-night)
- `vendor/reveal/` — reveal.js 4.6.1 + плагин подсветки кода
- `vendor/fonts/` — Golos Text + JetBrains Mono, woff2 (кириллица + латиница)

## Требования к следующим урокам

Новый урок = новая директория `lessons/NN-тема/` с копией той же структуры:
`index.html` + `theme/` + `vendor/` (reveal + fonts). Тему курса и вендор
копируем из этого урока.
